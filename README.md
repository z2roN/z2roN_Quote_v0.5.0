# z2roN_Quote (비교견적서) v0.5.0
견적의뢰 업체의 엑셀을 불러와 **우리 견적**과 **타업체 견적(우리 단가 × 인상률)** 을 업체별 견적서(見積書) 엑셀로 만들어 내려받는 Windows 프로그램 (C# WinForms, .NET 8).

- 엑셀 불러오기: 파일 찾기 / 끌어다 놓기 (.xls .xlsx .csv, 첫 시트, 머리글 자동 인식 + 수동 열 지정)
- 설정: 우리 업체, 타업체(최대 3개, 우리 견적서 제외), 업체별 도장(PNG, 흰 배경 투명 처리), 기본/업체별 인상률, 단가 끝자리 처리, 쪽당 품목 수
- 견적마다 타업체 선택, 업체별 단가 직접 수정, 이 견적에만 적용되는 업체 정보 수정
- 바코드 수집: 스캔하면 품목 추가·수량 +1, 새 바코드는 이름/단가 입력해 상품 목록에 저장, 견적 저장 시 자동 수집
- 저장 / 완료 / 목록 조회 / 수정, 관리자 비밀번호는 선택(만들면 완료된 견적 삭제에 필요)
- 백업(폴더 지정, 완료 시 자동 백업) / 복원(관리자), 삭제·복원 기록
- 데이터: 내 문서\z2roN_Quote\견적자료.zqdb (SQLite)
- 빌드: .github/workflows/build.yml (GitHub Actions, 단일 exe)
